# 赵林苒 · 小组成长激励榜

## 项目介绍

这是一个基于根源优课真实课程报告生成的移动端静态 H5 榜单页，用于家庭学习激励展示。

- 全班成长排名：按本课全班有效课程报告计算
- 小组成长排名：按本地配置的小组名单在全班有效报告中二次计算

## 如何本地打开

直接双击 `index.html` 即可打开。

## 如何修改孩子姓名和课程数据

页面静态数据已经拆分到当前目录下的 `summary.json` 和 `boards/*.json` 中。

## 如何修改榜单 TOP10

重新运行生成脚本，切换课程或更新本地小组名单后，会自动重写 `summary.json` 和 `boards/*.json` 中的榜单数据。

## 说明

- 这是家庭激励榜，不代表官方排名。
- 项目本身不请求任何外部接口，也不会上传任何数据。
- 生成阶段使用真实课程接口，本页面是生成后的本地静态结果。
